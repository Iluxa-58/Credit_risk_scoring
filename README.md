# Credit Risk Scoring

Проект по оценке вероятности возникновения проблем с погашением кредита.

## Задача

Построить модель бинарной классификации, которая оценивает кредитный риск клиента.

Целевая переменная:

- TARGET = 0 — проблем с погашением не возникло;
- TARGET = 1 — возникли проблемы с погашением.
